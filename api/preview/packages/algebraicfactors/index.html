AlgebraicFactors

Finite toric potentials over named discrete channels, implementing L-SPEC-004 §0 and §1.1–§1.7, plus Grassmannian parameters (§2.1–§2.2). Messages, energies and entropies use exact enumeration; fitting uses Newton or binary-feature IPF. Sampson scalarisation and later algebraic factors are not implemented.

using AlgebraicFactors, LenticulumCore, Mycelium, Random, LinearAlgebra

names, alphabets = (:a, :b), (2, 3)
A = independence(names, alphabets)   # a design matrix, not a factor
f = ToricFactor(names, alphabets, A)
ps, st = setup(Random.Xoshiro(1), f)
p = Polarity(a = Unobserved(), b = Observed())
site, st = factor_message(f, :a, p, (b = DiracBelief(2),), nothing, ps, st)

Joint states are ordered with the first variable fastest, as in CartesianIndices. Default labels are 1:alphabet; custom labels are a tuple of unique-label vectors. Diracs match actual labels. Unlabelled categoricals are positional; labelled categoricals are matched and reordered by label. Shared graph variables need consistent canonical label order because Mycelium combines outgoing categorical messages positionally.

hierarchical builds a marginal-cell indicator block for each generator, named by tuples of channels or indices. Both matrix builders retain redundant statistics. Parameters are (η = …,), initially zero; the factor retains redundant statistics. Fitting returns the minimum Euclidean norm representative modulo constant logits and null directions.

factor_message excludes the target prior and target input. Latent channels enter with unit weight, and the factor supports every observed/latent combination around one target. This is a direct-message factor: it provides no assembled lens, joint latent posterior or forward model. The common conformance checker uses independent site and pooled-posterior fixtures through its direct-message path.

local_free_energy computes the joint factor expectation minus joint entropy from the incoming cavity messages. Mycelium supplies the variable entropy counting correction. Set normalised = true for standalone game quantities: free_energy(f, π, y, ps, st) and LenticulumCore.entropy(f, π, y, ps, st). Use disjoint NamedTuples of prior beliefs and observations, or one prior belief and observations naming every other channel.

fit_mle(f, counts; method = :newton, tol = 1e-10, maxiter = 1000) returns (η, p, converged, iterations, residual, existence). Counts can be a joint-state vector or an array of size alphabets. p is a vector; the parameter can be used with ps = (η = fit.η,). Newton removes the gauge by an SVD of centred logits; :ipf requires a 0/1 design and cycles over individual rows. At target moments zero or one, IPF uses finite log-odds steps of -32 or +32 to approximate the infinite endpoint update.

converged means the infinity norm of the moment residual is at most tol. existence == :exists certifies an ordinary MLE only when every count is positive. Otherwise it is :suspected_boundary when the centred logit norm has grown from zero to at least 10 and length(p)*minimum(p) <= 1e-8, or :unknown. The boundary status is a heuristic, not proof of non-existence; it can accompany moment convergence.

inmodel(f, p; atol = 1e-8) requires strictly positive probabilities and tests the Euclidean least-squares residual of log probabilities in the augmented row space [1'; A]. binomial_residuals(f, p, moves) permits zero probabilities and checks supplied integer moves in the exact kernel of [1'; A] before evaluating their binomials. No Markov basis is computed. Both check probability normalisation with atol=1e-12, rtol=1e-8, separately from the membership tolerance.

Positive independence tables and a decomposable chain are checked against their closed forms by both methods; the tests also cover an arbitrary integer design, likelihood finite differences, the gauge, empty-row extended MLEs and independence minors. The implementation note lib/AlgebraicFactors.jl/src/fit.md gives the numerical thresholds and limitations.

Grassmann(k, m) represents a row space by a real k × m matrix Θ with Θ * Θ' ≈ I. project_tangent(M, Θ, G) returns its horizontal gradient, retract(M, Θ, Δ) orthonormalises the rows with positive-diagonal thin QR, and ispoint(M, Θ; atol=1e-8) checks the representation. Retraction rejects non-finite or numerically rank-deficient input (see its docstring).

M = Grassmann(2, 6)
Θ = rand(Random.Xoshiro(2403), M)
r = Retracted(Momentum(0.04, 0.6), M)  # also accepts GradientDescent
state = zero(Θ)                       # use nothing for GradientDescent
of = OptimiserFactor(:θ, r)
S = Diagonal([-2.0, -1.0, 1.0, 2.0, 3.0, 5.0]) # using LinearAlgebra
state, Θ = optimiser_step(of, state, Θ, 2Θ * S)

Retracted preserves Mycelium's momentum recurrence s′ = -γ*s - η*grad and transports the velocity by projection onto the new horizontal space. Mycelium has no rule-state initializer; initialise it as above. Factor message emission reads (p=Θ, state=state). Nesterov and other rules are rejected: Nesterov's look-ahead leaves the manifold. The geometry tests check first-order descent and both optimisers against a known eigenplane, using η=0.04 for 400 iterations; they check factor-driven updates against direct rule_put at every step. The implementation note lib/AlgebraicFactors.jl/src/grassmann.md records the exact problem, tolerances and limitations. This uses the canonical Grassmann metric; it does not implement a statistical model's Fisher metric.

Enumeration costs grow with the product of alphabet sizes. This implementation uses CPU arrays and makes no GPU or automatic differentiation guarantee.

AlgebraicFactors.AlgebraicFactors — Module
AlgebraicFactors

Exact finite log-linear factors for Lenticulum and Mycelium. See ToricFactor, independence, and hierarchical. fit_mle fits moments; inmodel and binomial_residuals check supplied probabilities. Grassmann and Retracted provide Grassmannian parameter updates.

AlgebraicFactors.Grassmann — Type
Grassmann(k, m)

The real Grassmannian of k-dimensional subspaces of ℝ^m, with 1 ≤ k ≤ m. A point is represented by a real k × m matrix Θ with orthonormal rows. Representatives Θ and O * Θ for orthogonal O describe the same point. Geometry routines assume orthonormal input; use ispoint to check it.

AlgebraicFactors.Retracted — Type
Retracted(rule, M::Grassmann) <: Mycelium.AbstractUpdateRule

Wrap Mycelium.GradientDescent or Mycelium.Momentum with horizontal projection and QR retraction. All other rules throw ArgumentError. Nesterov is excluded because its look-ahead leaves the manifold; a retracted look-ahead and consistent gradient transport would need a separate contract.

rule_get(r, state, Θ) = Θ. rule_put projects the gradient, calls the inner rule, projects its candidate displacement, and retracts. Momentum's new state is the inner rule's plain k × m velocity matrix, transported by horizontal projection at the new representative. It uses Mycelium's recurrence s′ = γ*s - η*grad (heavy-ball momentum).

Mycelium has no rule-state initializer: supply nothing for gradient descent (its state is passed through unchanged), or zero(Θ) for momentum. Works with Mycelium.OptimiserFactor(:θ, r) and Mycelium.optimiser_step directly; message emission uses st = (p = Θ, state = state) as in Mycelium.

AlgebraicFactors.ToricFactor — Type
ToricFactor(names::Tuple, alphabets::Tuple, A::AbstractMatrix{<:Integer};
            normalised = false, labels = nothing)

Finite potential exp(dot(ps.η, A[:, x])), with one channel per name. Joint states follow CartesianIndices(alphabets): the first variable varies fastest. A has one column per joint state; its rows need not be independent or contain a constant. Parameters are (η = zeros(size(A, 1)),) initially (Float64); state is empty. The normalised distributions agree exactly when A' * (η - η′) is constant.

States are 1:alphabets[i], or labels[i] when a tuple of unique-label vectors is provided. Pointwise tuples and Diracs match labels by isequal, never by interpreting an integer label as a position. Unlabelled categorical inputs are positional; labelled ones must have exactly the channel's support and are reordered by label. Outgoing categoricals use the factor's label order (labels = nothing for default states).

Every polarity with one unobserved channel and all others observed or latent is supported. Missing, nothing, missing, TrivialBelief() and Latent() inputs have unit weight. Messages exclude both the target input and its prior. Enumeration visits all prod(alphabets) states; scoring also costs size(A, 1) per state. See fit_mle for fitting and inmodel for positive model membership.

AlgebraicFactors.binomial_residuals — Method
binomial_residuals(f::ToricFactor, p, moves) -> Vector{Float64}

Evaluate prod(p.^u⁺) - prod(p.^u⁻) for each supplied integer-vector move u. p is a finite non-negative probability vector/array in factor order, including boundary points. Every move must have length prod(f.alphabets), sum(u) == 0, and A*u == 0; these kernel checks use exact BigInt arithmetic. Invalid inputs throw ArgumentError. Products use log space, treating empty products as 1 and positive powers of zero as 0. A supplied collection need not be a Markov basis; vanishing on it alone does not certify general boundary membership. No basis is computed.

AlgebraicFactors.fit_mle — Method
fit_mle(f::ToricFactor, counts; method = :newton, tol = 1e-10, maxiter = 1000)

Fit the normalised model to finite non-negative real counts with positive total. counts is an array of size f.alphabets or a vector in joint-state order (first variable fastest). Calculations use dense CPU Float64 arrays and log probabilities.

Return (η, p, converged, iterations, residual, existence). p is a vector in factor order, reproduced by ps = (η = η,). η is the minimum Euclidean norm representative modulo ker((I - 11'/m)A'), computed by an SVD with relative cutoff max(size(A)...) * eps(Float64). residual = norm(A*p - A*counts/sum(counts), Inf); converged means exactly residual ≤ tol. iterations counts accepted Newton steps or complete IPF sweeps; an exhausted budget or stalled line search can return false.

:newton uses an orthonormal basis of centred logits, their covariance Hessian, and backtracking on the per-observation log-likelihood. Redundant rows and designs without a constant row are supported. :ipf requires entries in {0,1} and cycles over rows, exactly setting each binary feature's mean using its log odds. At target 0 or 1 the exact update is infinite; use a finite log-odds step of -32 or +32 per sweep instead, approaching the endpoint while retaining finite parameters.

existence is separate from convergence: :exists certifies the ordinary MLE only when every count is strictly positive (the target is then a positive convex combination of all columns, hence in their relative interior). Otherwise it is :suspected_boundary if the centred logit norm has grown from zero to at least 10 and m*minimum(p) ≤ 1e-8; it is :unknown otherwise. This heuristic is no proof of non-existence. A boundary extended MLE can satisfy the moment tolerance while its finite parameter approximations grow, so converged and :suspected_boundary can occur together. No LP existence test or exact boundary parameter is returned.

AlgebraicFactors.hierarchical — Method
hierarchical(names, alphabets, generators) -> Matrix{Int}

Design matrix with one block of marginal-cell indicator rows per generator, in the supplied order. Each generator is a tuple of distinct channel names or 1-based indices. Within a block, cells follow the generator's order, first listed variable fastest. Columns follow CartesianIndices(alphabets). Empty generators give a constant row; an empty generator collection gives a zero-row (uniform) model. Redundant blocks are kept.

The hierarchical design with singleton generators in channel order. For a 2×3 table there are five rows: two indicators for the first variable, then three for the second.

AlgebraicFactors.inmodel — Method
inmodel(f::ToricFactor, p; atol = 1e-8) -> Bool

Test positive model membership by least squares: log(p) must lie in the row space of [ones(1,m); A]. atol bounds the Euclidean (2-norm) projection residual in log probabilities, not a probability error. Uses the same SVD rank cutoff as fit_mle. p must be a finite, strictly positive probability vector or an array of size f.alphabets, in factor order; otherwise throw ArgumentError. Normalisation is checked with atol=1e-12, rtol=1e-8, independently of the membership tolerance. Boundary membership requires binomials; see binomial_residuals.

AlgebraicFactors.project_tangent — Method
project_tangent(M::Grassmann, Θ, G)

Return G - (G * Θ') * Θ. This is the horizontal lift of the Grassmann tangent space at the orthonormal representative Θ: Δ * Θ' = 0. It removes the vertical (row-basis rotation) directions from the Stiefel tangent space; it is not the full Stiefel tangent projection. Uses the Frobenius metric on horizontal lifts, with cost O(k²m).

source
AlgebraicFactors.retract — Method
retract(M::Grassmann, Θ, Δ)

Orthonormalise the rows of Θ + Δ by thin QR of its transpose, fixing signs so diag(R) > 0. Thus retract(M, Θ, zero(Θ)) ≈ Θ. For a retraction step, Θ must be orthonormal and Δ horizontal (see project_tangent); arbitrary displacements are also accepted as row orthonormalisation.

Throws ArgumentError on non-finite or numerically rank-deficient input: any abs(R[i,i]) ≤ max(k,m) * eps(T) * norm(R, Inf) is rejected, where T is the QR element type. This is a floating-point QR diagonal criterion, not an exact rank certificate. Dense real CPU arrays are the supported use.

LenticulumCore.free_energy — Method
LenticulumCore.free_energy(f::ToricFactor, π, y, ps, st)
LenticulumCore.entropy(f::ToricFactor, π, y, ps, st)

Exact scalar game quantities for normalised = true, using the same joint factor belief as local_free_energy. π is a NamedTuple of incoming channel beliefs and y a disjoint NamedTuple of observations (beliefs or labels). A single belief π is assigned to the sole channel omitted from y. nothing supplies no evidence; unspecified channels are summed with unit weight. Entropy is positive Shannon entropy.

Mycelium.factor_message — Method
Mycelium.factor_message(f::ToricFactor, target, polarity, inputs, prior, ps, st)

Exact sum-product site on target, integrating every other channel. prior and any target entry in inputs are excluded. normalised changes only a constant and hence does not affect the returned categorical probabilities. Returns (belief, st).

Mycelium.local_free_energy — Method
Mycelium.local_free_energy(f::ToricFactor, msgs, ps, st)

E_q[energy] - H(q) for the joint factor belief q ∝ exp(A'η) * prod(msgs). These are variable-to-factor messages, not variable marginals. No incoming-message energy is charged. Mycelium separately adds sum((degree(v)-1) * H(b_v)); adding that correction here would count it twice. Returns a scalar and the unchanged state.
