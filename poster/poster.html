1Function vs. relation

$$R_\theta=\{\,z\in Z:\ r_\theta(z)=0\,\}$$
  • Network: fit $f_\theta$, run forward only.
  • Lenticulum: fit a residual $r_\theta$; its zero set is the model.
  • Inputs and outputs are chosen at query time.

3A query is a precision vector

  • $\rho\in[0,\infty]^n$; polarity splits $Z=X\times Y\times U$, $P_x+P_y+P_u=\mathrm{Id}$.
  • One number per coordinate interpolates evidence ↔ unknown.
  • Precisions are differentiable too.

4Inference = root finding

$$r(z)=g_\theta(z)+\rho^2\odot(z-z_0)$$$$r_F(z^\star)=0,\qquad z^\star_C=z_{0,C}$$
  • $F$: free coordinates ($\rho_i<\infty$); $C$: clamped ones.
  • Multi-valued: one root per branch; warm start chooses.
  • No root (off the relation): the closest point.

5Backprop = implicit function theorem

$$J_{FF}^{\top}\lambda=-\bar z_F$$$$\bar\theta=\lambda^{\top}\partial_\theta r_F,\quad \bar\rho=\lambda^{\top}\partial_\rho r_F,\quad \bar z_0=\lambda^{\top}\partial_{z_0} r_F$$
  • Lagrangian $\ell(z)+\langle\lambda,r_F\rangle$: state eq. → adjoint eq. → gradient.
  • Gradients for parameters, inputs and precisions.
  • Noise nodes fixed: no noise stored. Checked against finite differences.

7Where residuals come from

Diffusion residual from a trained denoiser: $g_\theta=\sum_k w_k\lambda_{t_k}(\varepsilon_\theta(\cdot)-\varepsilon_k)$. Exact score ⇒ $g=\nabla\Phi$: RED-Diff's stop-gradient field is a gradient. Inference = proximal step. Zero noise ⇒ DEQ of Tweedie's denoiser.
Equilibrium DEQ: the layer's fixed point is a relation, shipped as a function. Neural ODE: an invertible factor.
Algebraic polynomial residuals → varieties. Fitting = nullspace; parameter = Grassmannian; composition = elimination. Toric models: exact discrete messages.
Adversarial implicit generators and density-ratio factors. GAN wiring = two parameter sets, three factor nodes; its objective fails by one sign.

8Factor graphs: wire relations

$$\mu_{f\to v}=c'_\pi(y)\quad\text{(a Bayesian inversion)}$$
  • Target channel → unobserved; incoming → observed; rest → latent.
  • Polarity is resolved per message; no step like it in Lux.
  • GTSAM's graphs, with learnable non-Gaussian factors.
  • Beliefs on edges: point, particles, Gaussian, categorical, mixture.

9Bethe free energy

$$F_{\text{Bethe}}=\sum_f F_f+\sum_v(1-d_v)\,F_v$$$$\textstyle\sum\kappa=|F|+|V|-|E|=\chi(G)$$
  • Graph version of AutoBayes' chain rule (Thm. 23): energies add, entropies overlap-corrected.
  • Counting numbers sum to the Euler characteristic.
  • Energy is graded: $E_G=\bigoplus_f E_f$ → per-factor loss attribution.

10Category theory, in one line

$$\underbrace{\mathbf{Para}(\mathbf{Lens})}_{\text{Lux layer}}\quad\text{vs.}\quad\underbrace{\mathbf{Para}(\mathbf{StatGame})}_{\text{Lenticulum factor}}$$
  • Factor = parameterized statistical game (AutoBayes, Def. 27).
  • Four choices: kernel $c$, inversion $c'$, energy $l$ (a vector), entropy $H$.
  • The lens is assembled on demand, once a polarity is chosen.
  • Not needed to use the code; background in the CT-ML wiki, Track E.

11Packages

Any Lux model wraps as a factor. AD per model via extensions: Zygote, Enzyme, ForwardDiff, Mooncake; Reactant compiles to XLA.

12Status

  • Exact on linear-Gaussian graphs and closed-form models; tests compare to closed forms.
  • Small nets by design: a factor's space has a few coordinates.
  • Point inference returns one branch; conditional sampling not yet.
  • Open problems are logged in the vault, not hidden.
