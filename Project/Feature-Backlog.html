overview

The features Lenticulum.jl should get, in one list: what each is for, where it was asked for, what measurement motivates it, and how far it is. A feature is added here when a specification, a problem, a review or a measurement asks for it, and moved to “done” with the commit that implemented it. Priorities are proposals until Daniel sets them.

Sources: original to this repository; the open lists of Specifications and Problem Log, LP-023 Findings of the external reviews of 2026-11-04.

Status: planned (specified or asked for, not started), proposed (an idea with a reason, no specification), partial, done. Priority: high (it limits something measured now), medium, low.

Utility factors and data (asked for 2026-11-05)

Daniel: “there should be a whole bunch of utility factors that are still lacking.” Mycelium has DataFactor, PriorFactor, LossFactor, RelayFactor (an equality between two variables), OptimiserFactor, TableFactor and StraightThroughFactor. Today the operations below are written by hand, from LinearConstraintFactors with selection matrices or from graph code.

Done (2026-11-04/05)

CI with a second Julia version and the device tests (2026-11-05). The matrix runs the current release and 1.12, the oldest supported. Two separate jobs run the Mycelium and ImplicitLayers device files (JLArrays). The supported minimum was declared as 1.10 but never tested, and it was wrong: the packages find each other through [sources], which needs 1.11, so on 1.10 every package but LenticulumCore fails to instantiate. On 1.11 the Enzyme backend of the DEQ solve fails (MixedReturnException, Enzyme 0.13.205); the same Enzyme passes on 1.12. All seven suites pass on 1.12, and every Project.toml now says julia = "1.12".

A warning for DEQFactors trained by their residual with the state observed (2026-11-05; measured in lib/ImplicitLayers.jl/test/lp022.jl). Cluster forms and closed-form M-steps for GaussianFactor and GaussianPrior, learned noise included (2026-11-05; test/em.jl).

Cluster nodes with per-outcome coefficients and noise (RegimeFactor); flat directions in clusters; output channels and the LP-022 warning (constraint and toric factors); fixes from the external reviews (LP-023); frozen paths inside cluster nodes; closed-form M-steps and SQUAREM-accelerated EM (fit_em), batched over plates; the message loop no longer specialised on the parameter tree; validate_parameters; beam search and final refit in examples/structure_clusters.jl.
