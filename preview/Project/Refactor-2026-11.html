overview design

The repository after the refactor of November 2026 (branch refactor): five packages built around three paths, the rest parked. This note says what is where, what is verified and by what, what is not, and how parked work comes back.

Sources: original to this repository; the review that preceded it is LP-024 Findings of the review of 2026-11-09; code: every Project.toml, .github/workflows/CI.yml, docs/make.jl

What changed against dev-danielb at 28b1a315:

  • The top-level package moved from the repository root to lib/Lenticulum.jl/. The root has no Project.toml.
  • Mycelium was split. Inference stayed; free_energy_gradient of a graph, parameter_step, the couplings, the graph adjoint, EM and sample_gradient are MyceliumLearning (MyceliumLearning has the boundary). Mycelium’s suite went from 6 minutes to 41 seconds.
  • ImplicitLayers, Adversarial and AlgebraicFactors are in parked/ with their tests and notes; tutorials 05 and 07 (they use ImplicitLayers) and the three packages’ documentation pages are with them. The vault notes on those families and on applications off the paths are in vault/Parked/.
  • meta/ and poster/ are outside the repository.
  • The shared test support (the factor conformance checker) is in lib/LenticulumCore.jl/test/support/.

What is not verified

  • About half of the source was read. Read: LenticulumCore, Mycelium except cluster_batch.jl, the Gaussian, nonlinear, composition, constraint and switching factors, m_steps.jl, implicit.jl, answers.jl, sampler.jl, schedule.jl. Searched only: likelihood.jl, regime.jl, noise.jl, exposure.jl, and the other files of VariationalDiffusion.
  • The documentation build passes locally (julia --project=docs docs/make.jl: the nine tutorials execute, the API pages and the vault build, no unresolved reference). It was not run in CI, and nothing was deployed.
  • The device (JLArrays) tests, the examples and the benchmarks were not run.
  • The parked packages’ suites were not run after the move, and two of them were broken by it: AlgebraicFactors’ tests included Lenticulum’s source files by their old path, and ImplicitLayers’ DifferentiationInterface extension extended Mycelium._gradient_message, which moved to MyceliumLearning (the extension did not load). Fixed on 2026-11-10: AlgebraicFactors takes Lenticulum and MyceliumLearning as test dependencies, ImplicitLayers depends on MyceliumLearning. All three suites pass (ImplicitLayers with and without the device files), and CI runs them in a separate job. A local Manifest.toml from before the move still points Lenticulum at the repository root (path = "../.."); delete it and instantiate again.
  • Expectation propagation’s free-energy claim, the likelihood factors’ Laplace and EP sites, and the learned-noise priors were not rederived.

Next steps on the paths

In the order I would take them. Each is small enough to finish and has an oracle.

  1. A belief type for linear relations (path A, C): the Gaussian-plus-flat decomposition of constraint §4.1 as a belief with exact combine and pushforward. It replaces _split_moments, _flat_message and the improper flag by one representation, and makes hard linear constraints exact.
  2. The parameter and state store by integer slot (path A): removes the quadratic cost; the partial fix (skip _setsubtree when a factor’s state is unchanged) is a few lines.
  3. A benchmark against RxInfer and a dense solve on the chain and on a mixture model (paths A, C): RxInfer is already a test dependency of Lenticulum.
  4. Calibration remedies for the implicit learner (path B): off-relation detection, and the comparison of noisefree_nodes with field_nodes on the calibration benchmark now that the bias of each is known.
  5. A query report (path B): converged, stable, the roots found from other starts, the conditioning of the answer; the pieces exist in ImplicitSolution, implicit_roots and the pullback’s conditioning check.
  6. A structure-search driver in the library (path C): today every search is example code (Feature Backlog, “Structure search and editing”).
  7. Sorting the tests: the graph-gradient tests on Gaussian factors are in Lenticulum’s suite; Lenticulum’s runtests.jl is 1 300 lines and VariationalDiffusion’s 2 000.

Moving things back

A parked package or note comes back when it is needed on a path, or when someone takes it up, and it comes back corrected: reviewed, with an oracle test, on the current interfaces.

For a package (parked/X.jl):

  1. git mv parked/X.jl lib/X.jl; in its Project.toml and test/Project.toml set the [sources] paths back to ../<Package>.jl.
  2. If it uses gradients, EM or parameter_step, add MyceliumLearning to its dependencies; the names that moved are listed in MyceliumLearning.
  3. Run its suite. Fix what the interface changes since it was parked broke.
  4. Review it as the core was reviewed: read it, rederive what it computes, add an oracle test on random instances for each message path, record what is found as a problem.
  5. Add it to the CI matrix, to docs/make.jl and docs/Project.toml, move its documentation page back from parked/docs/ and its tutorials from parked/tutorials/.
  6. Move its notes from vault/Parked/ to the folder of the path it serves, revise them against the code, and update Map of Content.

Decisions taken in the refactor that are yours to revisit

  • ImplicitLayers is parked, although tutorials 05 and 07 use its Picard solver. Keeping it would have kept a 20-minute suite and an unreviewed package in the core.
  • The split of Mycelium is inference against learning. Cluster nodes, plates, overlays and structure edits stayed in Mycelium: they are inference. A further split (the belief algebra down into LenticulumCore, cluster nodes into their own package) is possible and was not done.
  • Unscented defaults to α = 1 and validate refuses dimension mismatches: both change behaviour for existing callers.
  • The branch is pushed (origin/refactor). CI passed every job on 7de4488e (five packages on Julia 1 and 1.12, two device jobs); the parked packages have their own CI job since 2026-11-10.
  • Versions. The libraries are 0.0.1-dev; Lenticulum keeps its calendar version (20261015.1.0-proto, as in CITATION.cff), which the refactor had changed and was restored.
